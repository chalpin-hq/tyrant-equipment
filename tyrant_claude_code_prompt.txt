# TYRANT GEAR COMPENDIUM — CLAUDE CODE PROMPT

## What to build
A single self-contained HTML file (no frameworks, vanilla JS) that is a gear reference
and build tool for the mobile strategy game Tyrant. Three tabs:

1. GEAR REFERENCE — all 132 items in tables split by rarity tier (Legendary → Common).
   Columns: Item name | Slot | ATK | DEF | HP | Base stat | Affixes | Role tags
   Filters: by Slot, by Role (PvP Offense / PvP Defense / Gathering / Monster Den / Dungeon / Weekly Boss)

2. BUILD GUIDES — 6 role cards showing a complete recommended set per role with reasoning.
   Roles: Gathering, Monster Den, PvP Offense, PvP Defense, Daily Dungeon, Weekly Boss

3. BUILD YOUR OWN — dropdown per slot (6 slots), live stat totals (ATK/DEF/HP sum),
   and a role fitness bar chart (6 roles, 0-100%) showing how well the build serves each role.

Dark game aesthetic. Mobile-friendly.

## ITEM STATS — HOW THEY WORK

### ATK / DEF / HP
- Values in the CSV are at level 1, 0% quality
- BOTH quality AND level affect these stats
- Quality: 0–100%, rolled once on drop, permanent
- Level: scales up to rarity cap (Common Lv28, Uncommon Lv31, Rare Lv34, Epic Lv37, Legendary Lv40)
- Higher quality = higher starting value before level scaling

### Base stats (base_stat_pct / base_stat_type columns)
- Some items have a % bonus built directly into the item (e.g. Wanderer's Boots +15% March Speed)
- These ARE affected by quality roll (higher quality = higher % value)
- These are NOT affected by level — they do not increase when you level the item
- The value in the CSV is the 0% quality value; 100% quality will be higher (exact multiplier unknown)

### Affixes (affixes column)
- Guaranteed affixes: type is fixed, value rolls within stated range on drop
- The range (e.g. 0.6%–1.2%) represents 0% quality → 100% quality
- Random affix slots: both type AND value are rolled on drop
- Common items have no affixes
- Uncommon: 1 guaranteed affix, no random slots
- Rare: 1 guaranteed affix, often 1 random "Any Bonus" slot
- Epic: 1–2 guaranteed affixes, 1–4 random themed slots
- Legendary: 1–3 guaranteed affixes, 2–4 random slots
- A single quality roll affects ALL of the above simultaneously — it's one roll per item

## ROLE SCORING (for Build Your Own fitness bars)
Score each item 0–3 per role based on affixes/theme, multiply by rarity multiplier,
sum across all 6 slots, divide by max (18) for a percentage.

Rarity multipliers: common=0.45, uncommon=0.65, rare=0.82, epic=1.0, legendary=1.1

Role scoring rules:
- PvP Offense: PvP ATK base stat or set → 3; Army ATK / First Round Damage affix → 2; general offense theme → 1.5; March Speed → 1
- PvP Defense: PvP DEF base stat or set → 3; Garrison DEF affix → 2.5; Army DEF affix → 2; Army Health / defense theme → 1.5
- Gathering: Gather Speed / Gathering Yield affix → 3; specific resource gathering → 2.5; March Speed on economy theme → 2; economy theme → 1.5
- Monster Den: Monster Damage / Reduction affix or Beastlord's Hunt set → 3; Army ATK on offense non-PvP → 1
- Dungeon: Dungeon Damage affix or Shadow of the Crypt set → 3; Dungeon Dmg Reduction / Hero HP / Hero DEF → 2.5; Titanbreaker set → 2
- Weekly Boss: Titanbreaker set → 3; Dungeon Damage affix → 2; Hero HP / Hero ATK → 1.5

## KEY GAME MECHANICS

### Combat
- Troop counter triangle: Infantry beats Cavalry, Cavalry beats Archers, Archers beat Infantry
- Counter bonus: 25% damage advantage
- Damage split: 60% of damage goes to the dominant troop type, 40% spread
- Battle ends when one side reaches 60% losses
- Casualty split: 90% wounded (recoverable), 10% killed permanently
- Wall: 20% damage reduction at full HP, scales down as wall loses HP
- Frontline: at least 60% of the smaller army each round, replenished from reserves

### Heroes
- Heroes provide Command bonuses (stat boosts to the army they lead)
- Rarity caps on Command contribution: Common 17.15%, Uncommon 18.9%, Rare 20.7%, Epic 22.75%, Legendary 25%
- Gear counts ABOVE this cap — fully additive, equal on all hero rarities
- Hero HP drains at 30% of army loss rate in world battles (Sept 2026 patch)

### Abilities
- World abilities fire automatically based on a directive (Opening round / When losses run heavy / When winning / After their biggest hit / Save for late rounds / Never / Specific round)
- Instance abilities (dungeon/arena) use charges; charges don't replenish mid-dungeon
- Two abilities on the same directive = only ONE fires per battle — offset them

### Tactics
- Tactics have been removed from the game (as of recent patch)
